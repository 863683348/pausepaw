屏幕时间密码怎么用（为什么该用）

2026-11-06

密码是「限额」和「建议」的分界线。设置、找回一次讲完，再补上最需要它的两个设置。

屏幕时间密码是四位数字，它决定你设的限额是真限额还是一句建议。没有它，拿到手机的人可以从灰色界面里点「忽略限额」继续刷；有了它，限额才会真的停下来。这篇把屏幕时间密码怎么用一次讲完：设置步骤、找回方式，以及最需要密码保护的两个设置。

屏幕时间密码怎么设

打开「设置」→「屏幕使用时间」，拉到最底部。点「锁定屏幕使用时间设置」，旧版 iOS 叫「使用屏幕使用时间密码」。输入四位密码、确认，然后会出现「用 Apple ID 重置密码」的选项，选它。以前的找回方式是抹掉整台设备，这条 Apple ID 路径就是为取代它准备的。

密码本身有两条规矩。第一，不要和开机密码用同一个。孩子一周之内就能背下开机密码，两个密码相同等于没设。第二，如果是在「家人共享」里给孩子设备设，从你自己的手机上设，不要拿孩子的手机设。在孩子设备上输入的密码，等于当着孩子的面输入的密码。

用密码把 App 限额变成硬限制（restrict app limits）

App 限额是最容易设了又悄悄撤掉的设置。时间用完之后，灰色界面上有「忽略限额」按钮，同一个限额被忽略三次之后，这个数字就不再有任何意义。要把 restrict app limits 这件事做实，去「屏幕使用时间」→「App 限额」，打开「达到限额后阻止使用」。之后这个 App 会停到第二天，或者等有人输入密码。

这个组合才是设置真正生效的原因：限额画出边界，密码拦住改写。孩子的手机上没有密码的限额，只是一场多了几步手续的谈判。

密码到底保护了哪些设置

设置项密码拦住了什么
App 限额「忽略限额」按钮
停用时间偷偷延长时间表
内容与隐私访问限制改年龄分级和网页过滤
始终允许往白名单里加 App

再补一条共用设备的情况：「屏幕使用时间」里的「跨设备共享」会把 iPad 和 Mac 的使用算进同一份限额。开着它，一个密码守住账号下所有设备；关掉它，iPad 得单独设一个。

忘记密码怎么办

点「更改屏幕使用时间密码」→「忘记密码」，用当初设置时绑定的 Apple ID 验证。如果设置时跳过了那个选项，就没有找回路径了，只能抹掉设备。这也是为什么上一步里的 Apple ID 找回不是可选项。

密码管不到的部分

密码保护的是设置，不是习惯。它拦不住一个决心够大的孩子去借朋友的手机，也管不了没人争论的那几个小时。这个空档正是 pause-paw.shop 在补的：PausePaw 跑在浏览器里，你给自己设一个滚动时长，超过之后下一个页面晚十秒加载，不需要密码，也不需要谁来批准。

A screen time passcode is four digits that decide whether your limits actually hold. Without one, anyone holding the phone can tap Ignore Limit from the grey screen and keep scrolling. With one, an App Limit stops being a suggestion. This is the whole screen time passcode setup, plus the two settings where the code matters most.

Screen time passcode setup, start to finish

Open Settings, then Screen Time, and scroll to the bottom. Tap Lock Screen Time Settings, which older iOS versions call Use Screen Time Passcode. Enter a four-digit code, confirm it, and the option to recover it with your Apple ID appears. Choose that option. Recovery used to mean wiping the device, and the Apple ID path is what replaced it.

Two rules for the code itself. First, do not reuse the device passcode. Kids memorize the code they use to open the phone within a week, and a Screen Time passcode that matches it protects nobody. Second, if the phone belongs to a child under Family Sharing, set the code from your own device, not theirs. A passcode typed on the child's phone is a passcode the child watched you type.

Restrict app limits with Block at End of Limit

App Limits is the setting people set and then quietly undo. When the timer runs out, the grey screen offers Ignore Limit, and ignoring it three times in a row teaches everyone that the number means nothing. To restrict app limits so they stay restricted, go to Screen Time, then App Limits, and turn on Block at End of Limit. After that the app stays locked until the next day or until someone enters the passcode.

This combination is what makes the setting enforceable. The limit sets the boundary and the passcode stops the override. On a child's phone, restricting app limits without a code is just a negotiation with extra steps.

What the passcode actually protects

SettingWhat the passcode blocks
App LimitsThe Ignore Limit button
DowntimeQuietly extending the schedule
Content and Privacy RestrictionsChanging age ratings or web filters
Always AllowedAdding apps to the whitelist

One more, if you share devices: Share Across Devices, under Screen Time, counts iPad and Mac usage against the same limits. Keep it on and one passcode guards every device on the account. Turn it off and the iPad needs its own code.

If you forget the code

Tap Change Screen Time Passcode, then Forgot Passcode, and authenticate with the Apple ID that was linked when the code was created. If that option was skipped during setup, there is no recovery path and the device has to be erased. This is why the recovery step in the setup section is not optional in practice.

What a passcode does not fix

A code protects settings, not habits. It cannot stop a determined kid from borrowing a friend's phone, and it does nothing about the hours nobody argues about.
