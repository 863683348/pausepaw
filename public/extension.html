下载 PausePaw 浏览器插件

让萌系伙伴在 Chrome / Edge 上守护你的屏幕时间，自动同步你在控制台设置的休息规则。

下载插件（.zip） 去控制台复制 Token

支持浏览器

Chrome、Edge 及任何基于 Chromium 的桌面浏览器（需支持 MV3 扩展）。手机端浏览器暂不支持。

加载方式

插件为「手动加载（开发者模式）」版本，非 Chrome 应用商店上架。每次更新需重新下载并刷新已解压目录。

安装步骤（约 1 分钟）

  1. 下载上面的插件包，解压得到文件夹（如 pausepaw-extension）。
  2. 在浏览器地址栏输入 chrome://extensions（Edge 用 edge://extensions）并回车。
  3. 右上角打开「开发者模式」开关。
  4. 点「加载已解压的扩展程序」，选择刚才解压的文件夹。
  5. 插件出现在列表后，点「固定」把它钉到工具栏，方便随时打开。
  6. 点工具栏的 PausePaw 图标打开弹窗，按下一步连接 Token。

连接 Token（开启云端同步）

  1. 打开插件弹窗，点「连接」。
  2. 粘贴你的设备 Token（在控制台「扩展」页点「复制 Token」获取）。
  3. 连接成功后弹窗会显示你的统计；之后在控制台改规则，插件会自动拉取生效。
提示：Token 等同于你的账号钥匙，请勿泄露给他人。
