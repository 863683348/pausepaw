# PausePaw 100 天博客规划

> **项目**：[https://pause-paw.shop/](https://pause-paw.shop/) — 浏览器端的「数字健康伴侣」，到点用萌系伙伴 + 不可跳过倒计时温柔打断 X/YouTube/TikTok/Reddit 等社交短视频刷屏。
> **目标**：100 天，每天一篇独立长尾关键词文章，被 Google 收录，建立 topical authority。
> **范围**：本文档只做规划，**不动手**。

---

## 0. 总体规划

### 内容架构（Pillar-Cluster）
- **Pillar（首页）**：[https://pause-paw.shop/](https://pause-paw.shop/) — 主词 *digital wellbeing / screen time control*
- **10 个 Cluster × 10 篇 = 100 篇**

### 内容生产流程（每天）
1. 根据本规划确定当日 title / keywords / internal links
2. 写中英双语版（中英各一篇，长度 600–900 字起步，逐步加到 1200+）
3. 部署：扩展 `public/blog.html`，追加 `<article id="day-NN">` 区块 + 双语 `post-body`
4. 更新 `server.js` 的 `EN_META` 映射 + sitemap URL 列表
5. 跨平台外发：Dev.to + Medium + Quora + LinkedIn + Reddit（见截图策略表）
6. 提交 commit → push GitHub → 触发 Railway 自动部署
7. 在 Google Search Console 提交 sitemap + 单 URL 索引请求

### 内链模型（每篇都遵守）
- **1 条** → 首页（pillar）
- **1–2 条** → 同 cluster 内其他文章（hub-spoke）
- **1 条** → FAQ 或 app.html（产品页导流）
- **1 条** → 已有的 3 篇 starter 文章（post1/post2/post3）

### 结构化数据
- 每篇都包 `<script type="application/ld+json">` 用 `BlogPosting` schema（仿现有 post1-3 写法）
- 站点级别保持 `Blog` schema 在 `blog.html` 顶部

### 双语策略
- 中英双语都在 `public/blog.html` 里同 article 内（用 `<div class="post-body" lang="zh">` 和 `hidden` 的 `lang="en"` 平行两块）
- `server.js` 按 `?lang=en` 服务端直出 EN `<title>` + canonical
- hreflang 三组（zh / en / x-default）已在 sitemap 落地

### 外链策略（按截图）
| 平台 | 外链放置 | 每篇数量 |
|------|----------|----------|
| Dev.to | 正文中 2-3 处自然提及 + 文末 CTA | 1 |
| Medium | 正文 + 文末 "Check out the full tool" | 1 |
| Quora | 回答中 1-2 处 + 个人简介 | 1 |
| LinkedIn | 文章底部 | 1 |
| Reddit | 正文 1 条 | 1 |

CTA 链接统一 → `https://pause-paw.shop/`
